# ソース案内

最終更新: 2026-09-01

コードの地図。画面仕様は `画面設計/画面設計書.md`、モジュール境界は `詳細設計/詳細設計書.md`、実行環境は `環境/環境構成.md`。

```
URL → app/.../page.tsx → components/... → hooks / getRepository() → Supabase
```

トップだけ例外: サーバーが `getPublicRepository()` してから `HomePageClient` に渡す（5分 ISR）。文言は `t('...')`（正本 `messages/ja.ts`）。

```

├── app/                 URL と 1:1 の入口
```
