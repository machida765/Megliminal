# 要件定義書

最終更新: 2026-09-01（現行実装に同期）

画面の詳細は [`画面設計書.md`](../画面設計/画面設計書.md)、内部構造は [`詳細設計書.md`](../詳細設計/詳細設計書.md)。

---

## 1. 目的

インターネット上のおすすめ（動画・本・映画など）を、ジャンル付きの短い投稿として共有する Web アプリ。匿名でも眺めて探せ、ログインすると投稿・いいね・コメント・保存ができる。

---

## 2. 概要

- 名称: メグリミナル（Meguriminal）
- 形態: ブラウザ向け Web（Next.js）。スマホ幅必須。ネイティブアプリは対象外
- データ: Supabase（Auth + PostgreSQL）。権限の正本は RLS
- コアルール:
  - 投稿は大ジャンルを必ず1つ持つ。中ジャンルは任意
  - タグは大ジャンルに依存しない横断ラベル（検索では使える。投稿フォーム UI は未接続）
  - **同一ユーザーは、同一大ジャンルへ 7 日に 1 件まで**（画面の事前チェック + DB トリガー）

## 3. 機能要件

### 3.1. 閲覧（未ログイン可）

| ID | 内容 |
| --- | --- |
| F-01 | トップで新着・人気・ランキング抜粋・検索導線を見る |
| F-02 | キーワード・ジャンル・タグ・期間で投稿を探す |
| F-03 | 投稿詳細（本文・外部リンク・いいね数・コメント）を見る |
| F-04 | ユーザーの公開プロフィールと投稿一覧を見る |
| F-05 | 投稿 / ジャンル / ユーザーのランキングを期間付きで見る |
| F-06 | 利用規約・プライバシー・クレジットを読む |

### 3.2. アカウント

| ID | 内容 |
| --- | --- |
| F-10 | メール + パスワードで登録・ログインする |
| F-11 | Google でログインする |
| F-12 | パスワードをメール経由で再設定する |
| F-13 | 表示名・アバター URL を自分で変える |
| F-14 | 退会する（物理削除。投稿等も CASCADE）。メールユーザーはパスワード再入力、Google のみは確認フレーズ |

### 3.3. 投稿・交流（ログイン後）

| ID | 内容 |
| --- | --- |
| F-20 | 投稿を作成・自分の投稿を編集・削除する |
| F-21 | 週1制限に引っかかったら「あと○日」と分かる |
| F-22 | いいねの付与・解除。件数は詳細・カード・ランキングに反映 |
| F-23 | コメントの投稿。自分のコメントを編集・削除 |
| F-24 | ブックマークの追加・解除と一覧 |
| F-25 | 不適切な投稿を通報する（理由 + 任意詳細） |
| F-26 | 自分のフィードから投稿を非表示にする（本体は消さない） |

### 3.4. 管理（admin ロール）

| ID | 内容 |
| --- | --- |
| F-30 | 大ジャンルの追加・並び・表示切替・削除（投稿があると削除不可） |
| F-31 | 未対応通報を見て、対象投稿を削除し通報を解決する |
| F-32 | 他人のコメントを削除できる |
| F-33 | 一般ユーザーは `/admin` に入れない（画面 + ミドルウェア + RLS） |

admin の初回付与は SQL。クライアントからの昇格は不可。他人の投稿本文は編集しない。

### 3.5. 未着手（要件には残すが現行 UI なし）

| ID | 内容 | 状態 |
| --- | --- | --- |
| F-40 | 投稿時のタグ選択 | repository / 検索のみ |
| F-41 | 管理画面のタグ CRUD | 未接続 |
| F-42 | 管理画面のユーザー権限変更 | SQL のみ |
| F-43 | アバターのファイルアップロード | URL 入力のみ |

## 4. 非機能要件

| ID | 内容 |
| --- | --- |
| N-01 | スマホ幅で主要画面が使える（ナビはアイコン中心、フォームは1カラム） |
| N-02 | 文言は i18n キー経由（正本 `messages/ja.ts`）。現状表示は日本語固定 |
| N-03 | トップは全員共通キャッシュ（ISR 5分）。個人の非表示はトップでは効かない |
| N-04 | 書き込みは RLS で拒否する。画面のボタン非表示は補助 |
| N-05 | `service_role` はサーバーの退会 API 以外に出さない |
| N-06 | ログイン後リダイレクトは同一オリジンのパスのみ |
| N-07 | 投稿 URL・アバター URL は http(s)（または安全な相対パス）に制限 |
| N-08 | 入力長: タイトル 100、本文・コメント 1000 |
| N-09 | 自動テスト: 単体（Vitest）/ RLS 結合 / Playwright E2E。詳細は [`テスト方針.md`](../テスト方針.md) |

## 5. スコープ

**今やる（実装済みまたは本リリース対象）**

- Web の閲覧・認証・投稿 CRUD・いいね・コメント・ブックマーク・ランキング・通報/非表示・退会・法務ページ
- Docker または Cloud の Supabase

**やらない / 後回し**

- React Native、プッシュ通知、下書き、フォロー、検索履歴、退会前エクスポート、再登録クールダウン
- 公開 REST API（`/api/v1/...` は作らない）
- ジャンル固有フィールド（`posts.attrs` はテーブル側の将来枠）

## 6. 関係者

| 役割 | できること |
| --- | --- |
| 匿名閲覧者 | 見る・探す。書く操作はログインへ |
| ログインユーザー | 投稿・交流・自分のプロフィール・退会 |
| 管理者 | ジャンル管理・通報対応・コメント削除 |
| 運用 | `.env`、Supabase、admin の SQL 付与、規約ドラフトの法務確認 |
