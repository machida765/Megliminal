# 手動テスト チェックリスト

自動テスト（Vitest / Playwright）が通っていても、**自分の目で触って確認する項目**の一覧です。  
リリース前・大きな機能追加後・本番デプロイ直前にこのファイルを開いて進めてください。

関連: [`../テスト方針.md`](../テスト方針.md)（自動テストの走らせ方） / [`../環境/Docker起動停止.md`](../環境/Docker起動停止.md)

---

## 使い方

1. 実施日と環境を下の「実施記録」に書く。
2. 項目を上から（または優先度 P0 から）触る。
3. OK なら `- [ ]` を `- [x]` に変える。NG ならメモ欄に症状を書く。
4. 全部終わったら実施記録の結果を更新する。
5. **次のラウンドでは `[x]` を `[ ]` に戻す**（このファイルをコピーして日付付きにするのも可）。

優先度:

| 記号 | 意味 |
| --- | --- |
| **P0** | 壊れているとリリースできない（認証・権限・データ消失・投稿 CRUD） |
| **P1** | 主要機能。リリース直前までに確認したい |
| **P2** | あると安心。時間があれば |

| 項目 | 記入欄 |

| ブラウザ | Chrome / Edge / Firefox / スマホ |
| 結果サマリ | 未実施 / 一部NG / 全OK |

### 使うアカウント（事前に用意）

| 役割 | メール等 | メモ |
| --- | --- | --- |
| 一般ユーザー A | | 投稿・いいね・コメント用 |
| 一般ユーザー B | | 他人操作の拒否確認用 |
| 管理者 | | `/admin` 用。profiles.role = admin |
| OAuth ユーザー（任意） | Google 等 | 退会フレーズ確認用 |

> 週1投稿制限があるので、**同じ大ジャンルで何度も投稿を試すときは別ユーザー or 別ジャンル**を使う。

### 起動確認（毎回最初に）

- [ ] `npm run supabase:status` で API が生きている
- [ ] `npm run dev` で http://localhost:3000 が開く
- [ ] トップページが表示される（白紙・NetworkError でない）

## 1. 認証・セッション 【P0】

### 1.1 新規登録

- [ ] `/signup` でメール＋パスワード登録できる
- [ ] 必須未入力だとエラーが出る
- [ ] パスワード不一致・短すぎるパスワードが弾かれる
- [ ] 既存メールで登録すると「すでに登録されています」系が出る
- [ ] 登録後、期待どおりログイン or 確認メール案内になる（ローカル設定に依存）

### 1.2 ログイン / ログアウト

- [ ] `/login` で正しい資格情報でログインできる
- [ ] 間違ったパスワードでエラーが出てログインできない
- [ ] ログイン後、ナビの「ログイン」が消えプロフィール導線になる
- [ ] プロフィールの「退出」でログアウトできる
- [ ] ログアウト後に `/create` を開くと `/login` に飛ぶ

### 1.3 保護ページのリダイレクト

未ログインで以下へアクセスすると `/login`（と redirect）へ飛ぶこと:

- [ ] `/create`
- [ ] `/bookmarks`
- [ ] `/profile/edit`
- [ ] `/settings`
- [ ] `/admin`

### 1.4 オープンリダイレクト対策

- [ ] `/login?redirect=/create` → ログイン後 `/create` に戻る
- [ ] `/login?redirect=https://example.com` → 外部へ飛ばず同一オリジン内に留まる
- [ ] `/login?redirect=//evil.example` → 同様に拒否される

### 1.5 パスワードリセット（メールが届く環境なら）

- [ ] `/forgot-password` で送信できる
- [ ] メール内リンクから `/reset-password` で更新できる
- [ ] 更新後、新パスワードでログインできる
- [ ] 古いパスワードではログインできない

### 1.6 Google OAuth（設定済みなら）

- [ ] 「Google でログイン」が動く
- [ ] キャンセル時にアプリ側で落ちない
- [ ] ログイン後にプロフィールが作られている

## 2. 投稿 CRUD 【P0】

### 2.1 作成

- [ ] `/create` で大ジャンル必須・タイトル・説明を入れて投稿できる
- [ ] 必須欠けだとアラート or エラーで投稿できない
- [ ] 投稿後、トップ or プロフィールに表示される
- [ ] 詳細 `/post/[id]` でタイトル・本文・ジャンルが見える
- [ ] 任意の URL を付けた投稿でリンクが開く（http/https のみ）
- [ ] `javascript:...` など危険スキームは保存時に弾かれる / 表示されない

### 2.2 週1制限

- [ ] 同じ大ジャンルに続けて投稿すると「あとN日」系で止まる
- [ ] **別の大ジャンル**ならすぐ投稿できる

### 2.3 編集

- [ ] 自分の投稿詳細に「編集する」が出る
- [ ] `/post/[id]/edit` でタイトル・説明を更新できる
- [ ] 更新後、詳細に反映されている

### 2.4 削除

- [ ] 「削除する」→ 確認ダイアログ → 削除できる
- [ ] 削除後、詳細 URL を開くと「投稿が見つかりません」
- [ ] プロフィールの投稿一覧からも消えている

### 2.5 権限

- [ ] 他人の投稿詳細に「編集する」「削除する」が**出ない**
- [ ] （可能なら DevTools で他人投稿を update しても反映されない / RLS で拒否）

## 3. 交流機能 【P1】

### 3.1 いいね

- [ ] 未ログインでいいね押すとログイン誘導になる
- [ ] ログイン後、いいねで件数が +1 される
- [ ] もう一度押すと解除され件数が戻る
- [ ] リロードしてもいいね状態が維持される
- [ ] ランキング（いいね順）におおよそ反映される

### 3.2 ブックマーク

- [ ] 投稿詳細で「保存」→「保存済み」になる
- [ ] `/bookmarks` にその投稿が出る
- [ ] 解除すると一覧から消える
- [ ] 未ログインで `/bookmarks` はログインへ飛ばされる

### 3.3 コメント

- [ ] 投稿詳細でコメントを投稿できる
- [ ] 空コメントは送れない
- [ ] 自分のコメントを編集できる
- [ ] 自分のコメントを削除できる
- [ ] 他人のコメントには編集が出ない
- [ ] 未ログインだとログイン誘導が出る

## 4. 通報・モデレーション 【P1】

### 4.1 一般ユーザー

- [ ] 他人の投稿で「通報」できる（理由選択＋任意詳細）
- [ ] 送信後「受け付けました」系が出る
- [ ] 「非表示」で自分の画面からその投稿が消える（他人の画面には残る）
- [ ] 自分の投稿は通報・非表示の対象外 or 操作できないこと（仕様どおり）

### 4.2 管理者

- [ ] `/admin` → モデレーションタブに pending 通報が見える
- [ ] 投稿タイトルから詳細へ飛べる
- [ ] 一括選択して削除できる
- [ ] 削除後、通報が解決済みになり pending から消える
- [ ] **一般ユーザーは `/admin` に入れない**（トップへ or 権限エラー）

## 5. 管理画面・カテゴリ 【P1】

- [ ] admin で `/admin` が開ける
- [ ] 大カテゴリを追加できる
- [ ] 並び順の上下が効く（トップや投稿フォームの表示順が変わる）
- [ ] 非表示にすると一般画面の選択肢から消える
- [ ] 再表示できる
- [ ] **投稿が付いているカテゴリは削除できない**（エラーメッセージが出る）
- [ ] 投稿のないカテゴリは削除できる

### 6.1 検索 `/search`

- [ ] キーワードでヒットする
- [ ] 大ジャンル絞り込みが効く
- [ ] タグ絞り込みが効く（タグがある場合）
- [ ] 期間フィルタが効く
- [ ] 条件クリアできる
- [ ] URL の `?q=` 等で入ったとき初期条件が反映される

### 6.2 ランキング `/ranking`

- [ ] 投稿ランキングが表示される
- [ ] 期間（週 / 月 / 全期間）切替で件数が変わる
- [ ] ユーザーランキング（投稿数 / いいね数）が表示される

### 6.3 トップ `/`

- [ ] 人気・最近の投稿が出る
- [ ] 検索ボックスから `/search` へ飛べる
- [ ] 各カードから詳細へ飛べる

## 7. プロフィール・退会 【P0】

### 7.1 プロフィール

- [ ] `/profile/[userId]` に自分の投稿一覧が出る
- [ ] 「プロフィールを編集」で表示名を変更できる
- [ ] アバター URL（相対 or https）を設定できる
- [ ] 危険なアバター URL は弾かれる

### 7.2 退会（**本番では捨てアカウントで**）

場所: プロフィール編集 → 「退会する」 or `/profile/edit#delete-account`

- [ ] 警告文と同意チェックがある
- [ ] メール登録ユーザーはパスワード確認が必要
- [ ] OAuth のみユーザーは確認フレーズ「退会する」が必要
- [ ] 退会後、そのアカウントでログインできない
- [ ] 退会ユーザーの投稿・コメントが消えている（CASCADE）
- [ ] 退会後に `/create` 等はログインへ飛ぶ

## 9. セキュリティ・壊れ方の確認 【P0】

ブラウザ操作だけで確認できる範囲:

- [ ] 一般ユーザーで `/admin` URL 直打ち → 入れない
- [ ] ログアウト後にブラウザ戻るボタンで保護ページの内容が見えない / すぐログインへ
- [ ] 投稿本文に `<script>alert(1)</script>` を入れても実行されない（文字として表示）
- [ ] プロフィール名に HTML を入れてもタグが実行されない

（任意・開発者向け）

- [ ] Network タブで `service_role` / `sb_secret_` がクライアントへ出ていない
- [ ] `npm run build` が通る
- [ ] `npm test` / `npm run test:integration` / `npm run test:e2e` が通る

## 編集のコツ

- 項目を足すときは同じ形式で `- [ ]` を追加するだけでよい。
- 機能単位で見出し（`##`）を増やすと後から探しやすい。
- 「今回は触らない」項目は消さず、実施記録のメモに「スキップ: ○○」と書くと履歴が残る。
- ラウンドごとに履歴を残したい場合:

  ```
  設計書/テスト計画/実施履歴/2026-09-01.md
  ```

  のようにこのファイルをコピーして日付を付ける。
