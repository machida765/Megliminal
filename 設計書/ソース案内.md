# ソース案内（ページ単位）

画面からコードを追うための短い地図です。画面の見た目の詳細は `画面設計/画面設計書.md`、フォルダ全体は `ファイル構成.md`、実行環境は `環境構成.md` を見てください。

## 読み方

1. **URL** は `app/` のフォルダと対応する（例: `/search` → `app/search/page.tsx`）。
2. `page.tsx` は入口。見出し・権限チェック・データの受け渡しだけであることが多い。
3. 見た目の本体は `components/`。投稿・検索などの計算は `lib/`。
4. 画面は `getRepository()` または `lib/data/hooks.ts` の `useXxx` 経由でデータを取る。接続先は `.env.local` の Supabase URL（Docker か Cloud）。
5. 文言は `t('...')`。定義は `messages/ja.ts`。

```
URL → app/.../page.tsx → components/... → hooks / getRepository() → Supabase
```

## 全ページ共通

| ファイル | 役割 |
|---|---|
| `app/layout.tsx` | 全画面の枠。ナビ、言語、認証 |
| `components/layout/Navbar.tsx` | ヘッダー |
| `components/providers/AuthProvider.tsx` | `useAuth()`。中身は Supabase Auth |
| `components/providers/LocaleProvider.tsx` | `useTranslations()` / `t()` |
| `lib/data/index.ts` | クライアント用 `getRepository()` |
| `lib/data/server.ts` | サーバー用。トップの ISR は `getPublicRepository()` |
| `middleware.ts` | セッション更新 |

## `/` トップ

- **誰でも**見られる。人気投稿・最近の投稿・検索への導線。
- **入口**: `app/page.tsx`（サーバーで取って `HomePageClient` に渡す。5分キャッシュ）
- **本体**: `components/home/HomePageClient.tsx`
- **データ**: `getHomePageData()`

---

## `/search` 検索

- **誰でも**。ジャンル・タグ・期間・キーワードで絞る。
- **入口**: `app/search/page.tsx`（`Suspense` は URL の `?q=` を読むため）
- **部品**: `CategoryPicker`、`SearchPeriodFilter`、`PostCard`
- **絞り込み計算**: `lib/search.ts` の `filterAndSortPosts`
- **データ**: `usePosts` ほか（投稿を一括取得してブラウザ側でフィルタ）

---

## `/ranking` ランキング

- **誰でも**。タブは投稿 / ジャンル / ユーザー。期間フィルタあり。
- **入口**: `app/ranking/page.tsx`（このファイルに UI がある）
- **データ**: `usePostRankings` / `useUserRankings`

---

## `/create` 新規投稿

- **ログイン想定**。フォームは共通部品。
- **入口**: `app/create/page.tsx`
- **本体**: `components/post/PostForm.tsx`（`initialPost` なし＝新規）
- **データ**: `createPost`（フォーム内）

---

## `/post/[id]` 投稿詳細

- **誰でも**閲覧。いいね・ブックマーク・通報・非表示はログイン後。編集は本人。
- **入口**: `app/post/[id]/page.tsx`（URL の `id` を取る）
- **本体**: `components/post/PostDetail.tsx`
- **データ**: `usePost`

---

## `/post/[id]/edit` 投稿編集

- **投稿者本人のみ**。他人なら詳細へ戻す案内。
- **入口**: `app/post/[id]/edit/page.tsx`
- **本体**: `PostForm` に `initialPost` を渡す

---

## `/bookmarks` ブックマーク

- **ログイン必須**。未ログインはログインへ。
- **入口**: `app/bookmarks/page.tsx`
- **データ**: `useBookmarks`

---

## `/profile/[userId]` プロフィール

- **誰でも**。その人の投稿一覧。自分なら編集ボタン。
- **入口**: `app/profile/[userId]/page.tsx`
- **データ**: `useUser` / `usePostsByUser`

---

## `/profile/edit` プロフィール編集

- **ログイン必須**。表示名・アバター。
- **入口**: `app/profile/edit/page.tsx`（このファイルにフォームがある）
- **保存**: `getRepository().updateUser`

---

## `/login` / `/signup`

- **入口**: `app/login/page.tsx` / `app/signup/page.tsx`
- **本体**: `LoginForm` / `SignupForm`
- Google ボタンは supabase のときだけ出る。
- OAuth 完了後: `app/auth/callback/route.ts`（画面ではない）

---

## `/admin` 管理

- **管理者向け**（画面側の制限。本番の拒否は DB の RLS）。
- **入口**: `app/admin/page.tsx`（カテゴリ CRUD はこのファイル）
- **通報タブ**: `components/moderation/AdminModeration.tsx`
