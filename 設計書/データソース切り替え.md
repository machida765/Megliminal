# データソース切り替えガイド

メグリミナルは **Local（ダミーデータ）** と **Supabase** を環境変数1つで切り替えられます。

## 切り替え方法

`.env.local` の `NEXT_PUBLIC_DATA_SOURCE` を変更し、開発サーバーを再起動します。

```env
# 画面開発中（デフォルト）
NEXT_PUBLIC_DATA_SOURCE=local

# Supabase 接続テスト
NEXT_PUBLIC_DATA_SOURCE=supabase
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
```

開発中はナビ左の **Local** / **Supabase** バッジで現在のモードを確認できます。

## 各モードの動き

| | Local | Supabase |
|---|---|---|
| データ | `data/dummy.ts` → インメモリ | PostgreSQL（Phase 3 で本接続） |
| 認証 | localStorage セッション | Supabase Auth |
| `/create` 保護 | なし（画面開発優先） | 未ログイン → `/login` |
| DB スキーマ | 不要 | 画面完成後に確定・実行 |

## 開発の流れ（推奨）

1. **Local モード**で全画面を完成させる
2. 画面から必要なデータ項目を洗い出し、`supabase/schema.sql` を確定
3. **Supabase モード**に切り替え、認証・DB 接続をテスト
4. Phase 3 で投稿 CRUD などを Supabase に接続

## アーキテクチャ

```
画面・コンポーネント
    ↓ hooks / getRepository()
DataRepository（interface）
    ├── LocalDataRepository  … local-store（インメモリ）
    └── SupabaseDataRepository … Supabase Client（Phase 3 で拡充）

認証
    ├── LocalAuthProvider   … localStorage
    └── SupabaseAuthProvider … Supabase Auth
```

画面から `@/data/dummy` を直接 import しないでください。必ず `getRepository()` または `@/lib/data/hooks` を使います。
