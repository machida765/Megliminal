# データソース切り替えガイド

データは **Supabase のみ**です。ブラウザ内の localStorage モードはありません。

切り替えるのは **Docker（PC 上）** と **Cloud（ネット上）** です。URL の違いで判定します。詳細は `環境/環境構成.md`。Docker の起動は `環境/Docker起動停止.md`。

## 切り替え方法

`.env.local` の URL とキーを入れ替え、開発サーバーを再起動します。

```env
# Docker
NEXT_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321
NEXT_PUBLIC_SUPABASE_ANON_KEY=（npm run supabase:status の anon key）

# Cloud
# NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
# NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
```

ナビ左の **Docker** / **Cloud** バッジで確認できます。

```
画面・コンポーネント
    ↓ hooks / getRepository()
SupabaseDataRepository
    ↓
Docker または Cloud の Supabase

認証
    └── SupabaseAuthProvider
```

画面から DB を直接叩かず、`getRepository()` または `@/lib/data/hooks` を使います。
