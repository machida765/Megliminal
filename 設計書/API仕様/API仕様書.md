### 3.1. [GET] /api/v1/posts

*   **説明**：投稿一覧の取得
*   **リクエスト**：
    *   クエリパラメータ：
        *   `category_id`：カテゴリID
        *   `tag_id`：タグID
        *   `keyword`：キーワード
*   **レスポンス**：

```json
[
  {
    "id": "post-001",
    "title": "ゆる言語学ラジオ",
    "description": "言語学をテーマにした解説チャンネル",
    "likeCount": 15,
    "createdAt": "2026-08-02T15:00:00.000Z"
  }
]
```
