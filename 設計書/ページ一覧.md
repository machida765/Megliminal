# ページ一覧

最終更新: 2026-09-23

メグリミナル本体（`app/`）の URL 一覧。見た目の仕様は `[画面設計/画面設計書.md](./画面設計/画面設計書.md)`、ファイルの場所は `[ソース案内.md](./ソース案内.md)`。

いまはログインなしの掲示板モード（`lib/auth/public-board.ts` の `PUBLIC_BOARD = true`）。閉じている画面のコードは残してある。ユーザー機能を戻すときはこのフラグを `false` にする。

`デザイン成果物/` は本番とは別のデザイン試作なので、ここには入れていない。

## 管理画面（裏）

未ログインで管理 URL を開くと `/admin/login` へ戻る。ログイン済みでも admin でない人は `/` へ戻る（`?error=forbidden`）。

admin の判定は `profiles.role = admin`。`ADMIN_USER_ID`（または `NEXT_PUBLIC_ADMIN_USER_ID`）が設定されているときは、そのユーザーだけが入れる。


| 画面       | URL                | 誰が開けるか      | 内容                                       | ファイル                           |
| -------- | ------------------ | ----------- | ---------------------------------------- | ------------------------------ |
| 管理者ログイン  | `/admin/login`     | 誰でもフォームは開ける | 掲示板モード中の管理者用ログイン。成功すると通報一覧へ              | `app/admin/login/page.tsx`     |
| 管理ホーム    | `/admin`           | admin       | 大カテゴリの追加・並び替え・表示切替・削除、アイコンと背景色。タブで通報対応。問い合わせへのリンク | `app/admin/page.tsx`           |
| 通報一覧     | `/admin/reports`   | admin       | 未対応の通報と、対象投稿の削除・対応済み                     | `app/admin/reports/page.tsx`   |
| 要望・問い合わせ | `/admin/inquiries` | admin       | `/contact` から届いた内容。未対応 / 対応済み            | `app/admin/inquiries/page.tsx` |

## コードはあるが、いまは開けない

掲示板モードのあいだは、次のとおり。フラグを戻すと「戻したあと」の列になる。


| 画面         | URL                 | いま                    | 戻したあと                                  | ファイル                            |
| ---------- | ------------------- | --------------------- | -------------------------------------- | ------------------------------- |
| ログイン       | `/login`            | 404                   | メールと Google でログイン                      | `app/login/page.tsx`            |
| 新規登録       | `/signup`           | 404                   | 表示名・メール・パスワード、Google                   | `app/signup/page.tsx`           |
| パスワード再設定依頼 | `/forgot-password`  | 404                   | リセットメールを送る                             | `app/forgot-password/page.tsx`  |
| 新パスワード     | `/reset-password`   | 404                   | メールリンクのあと、新しいパスワードを設定。ログイン必須           | `app/reset-password/page.tsx`   |
| プロフィール     | `/profile/[userId]` | ホームへ戻す                | アバターと投稿一覧。自分なら編集・ログアウト                 | `app/profile/[userId]/page.tsx` |
| プロフィール編集   | `/profile/edit`     | ホームへ戻す                | 表示名・アバター。下部に退会。ログイン本人                  | `app/profile/edit/page.tsx`     |
| 設定         | `/settings`         | 未ログインはホームへ戻す          | `/profile/edit#delete-account` へ転送するだけ | `app/settings/page.tsx`         |
| ブックマーク     | `/bookmarks`        | 未ログインはホームへ戻す。ナビには出さない | 保存した投稿。ログイン必須                          | `app/bookmarks/page.tsx`        |
| 投稿編集       | `/post/[id]/edit`   | 未ログインはホームへ戻す          | 投稿者本人だけ編集                              | `app/post/[id]/edit/page.tsx`   |
| 本棚         | `/shelf`            | 常に 404（フラグとは無関係）      | 同じ。公開するときはページ側の `notFound()` を外す       | `app/shelf/page.tsx`            |


本棚の見た目は `components/shelf/EndlessShelf.tsx` に残してある。
